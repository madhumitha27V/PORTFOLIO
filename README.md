# Madhumitha Portfolio (React + Node.js)

Professional portfolio rebuilt in React using content from the live reference site, styled with a polished orange and white design system.

## Tech Stack

- React
- Vite (Node.js build tooling)
- Plain CSS (custom theme)

## Sections Included

- Hero
- Skills
- Projects
- Achievements and Leadership
- Education
- Certifications
- Contact
- Footer

## Project Structure

```
PORTFOLIO/
├── index.html
├── package.json
├── vite.config.js
├── src/
│   ├── App.jsx
│   ├── data.js
│   ├── main.jsx
│   └── styles.css
└── README.md
```

## Run Locally

1. Install dependencies

```bash
npm install
```

2. Start development server

```bash
npm run dev
```

3. Build production bundle

```bash
npm run build
```

4. Preview production build

```bash
npm run preview
```

## Notes

- Content is mapped from https://madhumithav.vercel.app/
- Theme is intentionally orange + white with a professional layout
- All sections are data-driven via src/data.js for quick updates
- Use professional email for contact form
